# Data

Raw data is not committed to this repo. Download the datasets below and place them in `data/raw/`.

## Cell2Cell (primary training data — 71K subscribers, 58 features)
Source: Duke/Teradata Center for Customer Relationship Management, via Kaggle.
- Search Kaggle for "Cell2Cell Churn" and download `cell2celltrain.csv` / `cell2cellholdout.csv`.
- Place in `data/raw/cell2cell/`.

## IBM Telco Customer Churn (validation dataset — 7K subscribers, 21 features)
Source: IBM sample dataset, via Kaggle.
- Search Kaggle for "Telco Customer Churn IBM" and download `WA_Fn-UseC_-Telco-Customer-Churn.csv`.
- Place in `data/raw/ibm_telco/`.

## Notes
- `data/processed/` holds cleaned/feature-engineered outputs generated by the notebooks/pipeline — also gitignored.
- Never commit raw or processed data files; only code that generates them.
